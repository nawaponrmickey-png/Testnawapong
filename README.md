# ชุดสาธิตระบบ ปพ.5

ชุดนี้แยกจากระบบใช้งานจริงและใช้ข้อมูลนักเรียนสังเคราะห์เท่านั้น ห้ามนำฐานข้อมูล
รายชื่อนักเรียน เอกสารส่งออก ไฟล์สำรอง หรือความลับจากระบบจริงมาใส่ในชุดนี้

## ทดลองในเครื่อง

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
PP5_PASSWORD='ตั้งรหัสผ่านทดลอง' streamlit run app.py
```

## เผยแพร่ผ่าน GitHub และ Streamlit Community Cloud

1. สร้าง GitHub repository ใหม่สำหรับชุดสาธิตนี้โดยเฉพาะ แนะนำให้ตั้งเป็น Private
   และอัปโหลดเฉพาะไฟล์ในโฟลเดอร์นี้ ไม่ใช่โฟลเดอร์ระบบจริง
2. เชื่อม repository นี้กับ Streamlit Community Cloud แล้วเลือก `app.py` เป็นไฟล์เริ่มต้น
3. เพิ่ม Secret ชื่อ `PP5_PASSWORD` ในการตั้งค่าแอปของ Streamlit Cloud:

   ```toml
   PP5_PASSWORD = "ตั้งรหัสผ่านที่คาดเดายาก"
   ```

แอปจะไม่เริ่มทำงานจนกว่าจะตั้งรหัสผ่านใน Secret ของโฮสต์หรือ environment variable
ชื่อ `PP5_PASSWORD` และจะไม่ยอมเปิดหน้าใช้งานแบบไม่มีรหัสผ่าน

## ข้อจำกัดของชุดทดลอง

- ข้อมูลนักเรียนที่ปุ่มนำเข้าสร้างขึ้นเป็นข้อมูลสมมติ ไม่มีเลขประจำตัวประชาชน
- ระบบยังใช้ SQLite ในพื้นที่ของแอป ซึ่งบริการโฮสต์ฟรีอาจล้างข้อมูลเมื่อรีสตาร์ต
  หรือ deploy ใหม่ ข้อมูลที่แก้ไขจึงไม่รับประกันว่าจะคงอยู่
- ใช้สาธิตเท่านั้น ห้ามใช้เก็บข้อมูลนักเรียนจริงหรือข้อมูลอ่อนไหว
- การตั้ง repository เป็น Private ไม่ได้ทำให้ข้อมูลที่กรอกในเว็บเป็นระบบจัดเก็บถาวร
- ถ้าต้องการใช้งานจริง ต้องออกแบบฐานข้อมูลถาวร การกำหนดสิทธิ์ และการสำรองข้อมูล
  ก่อนนำข้อมูลนักเรียนขึ้นออนไลน์
